6. Tooling & Modeling Decision Matrix (Why X, Not Y) [ARCHITECTURAL TRADE-OFFS]

Pipeline Component Chosen Technique / Setting Rejected Alternatives Architectural Defense (Why This Choice Won)
Missing Value Strategy Convert 0 & Blanks to NaN, drop rows with ≥ 3 missing, Pipeline median imputation. Mean imputation; Mode imputation; Deleting all rows with any missing value; Leaving 0s as numbers. In this dataset, a score of 0 represents "unknown / unmeasured", not "zero ability" (a character with 0 intelligence would be braindead). Leaving 0s intact heavily corrupts distance metrics. Median imputation is robust to extreme outliers (0–100 scale). Dropping rows with ≥ 3 missing prevents hallucinating over 50% of a character's traits.
Imputation Leakage Defense SimpleImputer(strategy="median") nested inside scikit-learn Pipeline. Imputing the entire raw CSV upfront before splitting. Upfront imputation leaks test distribution information (medians) into training folds. Placing the imputer inside Pipeline guarantees the median is calculated strictly on training folds during 5-fold CV, and strictly on train.csv when evaluating test.csv.
Task 1 Classifier Scaling No scaling for Decision Tree; StandardScaler() required for KNN. MinMaxScaler; Scaling Decision Tree; Unscaled KNN. Decision Trees split on single-feature orthogonal thresholds; monotonic feature scaling has zero impact on Gini gain. In contrast, KNN uses Euclidean distance: unscaled features with larger standard deviations dominate distances. Z-score scaling gives equal weighting across all 6 ability dimensions.
Primary Evaluation Metric Macro-Averaged F1 Score (f1_macro). Raw Accuracy; Weighted F1; Micro F1. Clean Set B has moderate class imbalance (64.2% Hero vs. 35.8% Villain in train; 60.9% vs. 39.1% in test). A naive Dummy classifier attains 60.9% accuracy while catching zero villains. Macro-F1 weights both classes equally ((F1_Hero + F1_Villain) / 2), penalizing models that ignore villains.
Task 2 Clustering Selection Rule Highest Silhouette Score across k = 2..8 (tie-break: smaller k). Elbow method subjective choice; Fixed k=2; Davies-Bouldin minimization. Per the locked specification (Slide 24), the Elbow curve is descriptive only and cannot override Silhouette. Silhouette measures both intra-cluster cohesion and inter-cluster separation on normalized [-1, 1] scale. k = 2 scored 0.307 (highest), indicating a weak but genuine 2-tier structure.
Cluster Renumbering Ascending sort by overall mean ability score (0–100 scale); lowest = Cluster 1. Arbitrary cluster IDs; Renumbering by cluster size; Renumbering by Hero percentage. K-Means and Agglomerative assign arbitrary cluster indices (0, 1) based on initial seed centroids. Sorting by original 0–100 mean guarantees that Cluster 1 consistently represents lower-stat characters (Street-Level) and Cluster 2 represents high-stat characters (Cosmic) across both algorithms.
Neural Network Architectures Network A: 6 → 8 (ReLU) → 1 (Sigmoid) (65 params); Network B: 6 → 16 → 8 → 1 (257 params). Deeper ResNets; Adding Dropout; Adding BatchNorm; Extra neurons. Strictly enforced by Slide 30. Parameter derivation: Net A = (6*8 + 8) + (8*1 + 1) = 56 + 9 = 65; Net B = (6*16 + 16) + (16*8 + 8) + (8*1 + 1) = 112 + 136 + 9 = 257. Prohibits dropout or extra layers to test fundamental capacity scaling on tabular data.

7. The 4 Real Traps & Live Debugging Breakthroughs [WAR STORIES & RESILIENCE]

Trap 1: The Zero-Score Sentinel Trap (Missing vs. Zero Capability) DATA INTEGRITY

The Trap: Inspecting raw train.csv showed 0 missing cells in all 6 score columns. A naive pipeline would jump straight to modeling without cleaning.

The Reality: Cross-tabulating numeric distributions revealed 491 hidden 0 entries in train and 116 in test. In comic databases, 0 means "unknown / unmeasured". Treating 0 as true capability would mean powerful characters with unmeasured strength are placed beside ordinary mortals.

The Fix: Explicitly converted all 0s and blanks to NaN, dropped 86 + 20 weak rows with ≥ 3 missing scores, and imputed the remaining 1–2 missing scores via median inside scikit-learn Pipelines.

Verified: Table T1 & Table T2 row counts (1,158 → 1,072 in Clean Set A).
Trap 2: The Neural Network 80% vs. 100% Data Disparity METHODOLOGY

The Trap: An examiner asks: "Why did KNN (0.501) beat Network A (0.455) and Network B (0.421)? Are neural networks worse than KNN?"

The Reality: In Task 1, Decision Tree and KNN were tuned via 5-fold CV and then refitted on 100% of Clean Set B train.csv (916 rows). In Task 3, because EarlyStopping required an unseen validation split, Networks A and B were fit on only 80% of train.csv (732 rows)!

The Defense: This data volume difference is expected and mandated by Slide 31. Tabular datasets with small sample sizes (< 1,000) and low feature dimensions (6 inputs) inherently favor instance-based methods (KNN) over data-hungry multi-layer perceptrons.

Addressed in: Report Question Q11 & Table T10/T11 notes.
Trap 3: The Keras Trainable Parameter Math Trap DEEP LEARNING

The Trap: If an examiner asks you to calculate the trainable parameter counts on a whiteboard without running code, can you derive 65 and 257 exactly?

The Mathematical Proof:
• Network A (6 → 8 → 1): Layer 1 weights = 6 × 8 = 48, biases = 8. Layer 2 weights = 8 × 1 = 8, biases = 1. Total = 48 + 8 + 8 + 1 = 65.
• Network B (6 → 16 → 8 → 1): Layer 1 weights = 6 × 16 = 96, biases = 16 (112). Layer 2 weights = 16 × 8 = 128, biases = 8 (136). Layer 3 weights = 8 × 1 = 8, biases = 1 (9). Total = 112 + 136 + 9 = 257.

Asserted in code: assert params_A == 65 and params_B == 257 (Graph G12).
Trap 4: The Agglomerative Clustering .predict() Trap SCIKIT-LEARN API

The Trap: Unlike K-Means, scikit-learn's AgglomerativeClustering does not have a .predict() method for out-of-sample data, and Task 2 explicitly forbids using test.csv.

The Reality: In Task 2, all clustering must run strictly on Clean Set A (train.csv only, 1,072 rows). You must call fit_predict() on Clean Set A, compute linkage via SciPy (linkage(method="ward")), and fit PCA(n_components=2) once to project both K-Means and Ward clusters on identical coordinate axes.

Verified: Graph G8 & G9 share identical PC1 (49.9%) and PC2 (18.9%) axes.

8. Master Technical Viva Q&A (35+ Questions) [EXAMINER DEFENSE]

Q1: Can six ability scores tell a hero from a villain? What is the definitive answer? CORE HYPOTHESIS

Answer: No, they cannot. The highest test Macro-F1 achieved across all 5 models was only 0.501 (KNN), barely better than random chance. Furthermore, unsupervised clustering revealed that neither cluster is predominantly villains (K-Means clusters are 60.6% and 48.1% heroes; Ward clusters are 59.9% and 43.7% heroes). Ability scores measure power tier (street-level vs. cosmic powerhouse), not moral alignment. Morality is determined by narrative backstory, motivations, and choices—factors excluded when restricting inputs to ability scores.

Evidence: Report Executive Summary, Table T5, Table T8, Table T11.
Q2: Why did Decision Tree overfit so much more than KNN? MODEL DYNAMICS

Answer: Decision Tree selected max_depth=5, min_samples_leaf=10 during 5-fold CV (0.5405 CV Macro-F1) and achieved 0.563 Train Macro-F1. However, on test.csv it dropped to 0.408—a gap of 0.155, clearly violating the gap > 0.10 overfitting threshold. The tree created rigid rectangular decision boundaries around training clusters that failed to generalize. In contrast, KNN (k=9, uniform) smooths predictions over the 9 nearest Euclidean neighbors in standardized space, achieving 0.501 Test Macro-F1 with a train-test gap of 0.100 at 3 decimals (0.1003 unrounded). By the strict > 0.10 rule KNN also overfits, but only just (by 0.0003), whereas the tree overfits by a wide margin.

Evidence: Table T5, Graph G4, Answer Q4.
Q3: Which class is harder to predict, and why? CLASS IMBALANCE

Answer: Bad (Villain) is substantially harder to predict. In Clean Set B test data, there are 137 Heroes and 88 Villains. In Decision Tree (G2), only 6 of 88 Villains (6.8% recall) were detected. In KNN (G3), only 18 of 88 Villains (20.5% recall) were detected. In Network A (G15a), only 8 of 88 Villains (9.1% recall) were detected. Because Heroes outnumber Villains (~1.6:1 in test, ~1.8:1 in train) and power distributions overlap heavily, unweighted models default toward predicting the majority Hero class to minimize loss.

Evidence: Confusion Matrices G2, G3, G15; Answer Q3.
Q4: Why did Network B (257 params) fail to beat Network A (65 params)? NEURAL NETWORKS

Answer: Per Slide 35, we can only claim the deeper network improved results if Test Macro-F1 increases by at least 0.01. Network B achieved 0.421, which is 0.034 lower than Network A's 0.455. With only 732 training examples and 6 continuous features, adding a second hidden layer quadrupled parameter capacity (65 → 257) without adding feature representation capacity. Network B suffered higher optimization variance, triggered EarlyStopping at epoch 57 (vs. 151 for Network A), and displayed mild curve-based overfitting (validation loss rising while training loss continued dropping).

Evidence: Table T9, Table T10, Graph G13, Graph G14, Answer Q9 & Q10.

Action: Open superhero_project.ipynb to Cell 1–3 and show Table T1 & Table T2.

What to say: "Our project investigates whether six numeric ability scores—intelligence, strength, speed, durability, power, and combat—can distinguish a hero from a villain. We loaded 1,158 training characters and 290 test characters from Hugging Face across all publishers. In Table T1, notice that while there were zero raw blanks in the ability scores, we discovered 491 hidden zero-scores in train and 116 in test. Because a zero indicates unknown ability rather than zero capability, we marked zeros as NaN, removed weak characters with 3 or more missing scores, and prepared Clean Set A (1,072 rows for clustering) and Clean Set B (916 train / 225 test for supervised classification)."

Minute 2: Task 1 Classification & Overfitting Defense

Action: Scroll to Table T5 and Graphs G2, G3, G4.

What to say: "In Task 1, we evaluated a Dummy Baseline, Decision Tree, and KNN. On test data, KNN is the clear winner with a Macro-F1 of 0.501, outperforming Decision Tree (0.408) and Baseline (0.378). In confusion matrices G2 and G3, you can see that Decision Tree caught only 6 of 88 villains (6.8% recall), whereas KNN caught 18 (20.5% recall). Furthermore, Decision Tree suffered from severe overfitting: its train Macro-F1 was 0.563 compared to 0.408 on test—a gap of 0.155, which violates the 0.10 threshold. KNN's gap was 0.1003, so by the strict rule it overfits too, but only just, far less than the tree."

Minute 3: Task 2 Clustering & The Moral Alignment Reveal

Action: Scroll to Graphs G5, G6, G8, G9, and Table T8.

What to say: "In Task 2, we clustered Clean Set A without labels. The Silhouette Score strictly selected k = 2 (0.307), representing a weak but genuine 2-tier structure. K-Means outperformed Agglomerative Ward across all three internal metrics: Silhouette, Davies–Bouldin, and Calinski–Harabasz. When we project both clusterings onto identical 2D PCA axes (Graphs G8 and G9), we see a clean separation into Cluster 1 (Tacticians with low strength around 20) and Cluster 2 (Cosmic Powerhouses with power and durability above 80–90). Crucially, in Step 8 when we revealed the held-aside alignment (Table T8), neither cluster was mostly villains! Both clusters were over 48% heroes, proving that ability scores cluster characters by power tier, not morality."

Minute 4: Task 3 Neural Networks & Parameter Math

Action: Show Graph G12 (architecture diagram), Table T9, and loss curves G13 & G14.

What to say: "In Task 3, we constructed Network A (1 hidden layer, 8 neurons) and Network B (2 hidden layers: 16 then 8 neurons) using an 80/20 train/validation split. We verified their exact parameter counts: Network A has 65 trainable parameters, and Network B has 257. In the loss curves, Network A trained smoothly for 166 epochs with best validation loss 0.6208. Network B halted at epoch 72 via EarlyStopping with a higher validation loss of 0.6332. On test data, Network A scored 0.455 Macro-F1, while Network B scored 0.421. Because Network B performed 0.034 worse, we cannot claim that adding depth improved results."

Minute 5: Final 5-Model Ranking & Research Conclusion

Action: Show Table T11 and Graph G16.

What to say: "Finally, Table T11 ranks all five models on the unseen test set: KNN finishes 1st (0.501), Network A 2nd (0.455), Network B 3rd (0.421), Decision Tree 4th (0.408), and Baseline 5th (0.378). While all learned models beat the Baseline, it is important to note that Decision Tree and KNN had the advantage of training on 100% of Clean Set B, whereas the Neural Networks trained on 80% to allow EarlyStopping validation. In conclusion, six ability scores alone cannot reliably separate heroes from villains because superhumans share overlapping physical traits regardless of their moral compass."
